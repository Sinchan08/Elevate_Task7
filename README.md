# 🧾 Task 7 - Basic Sales Summary using MySQL and Python

This project was completed as part of a Data Analyst Internship Task.

---

## 📌 Objective

To connect Python to a MySQL database, run basic SQL queries, summarize sales data, and visualize the results using a bar chart.

---

## 🛠 Tools & Technologies Used

- **MySQL** — for creating and storing the sales database
- **Python** — main language used
- **pandas** — to load SQL query results into DataFrames
- **matplotlib** — to plot a bar chart
- **VS Code** — as the code editor
